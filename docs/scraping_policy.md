# 수집 정책 & robots 준수

## 목적
- 외부 사이트 수집 시 준수해야 할 기준을 명확히 하여 법적/운영 리스크를 최소화한다.
- robots.txt 및 서비스 약관을 존중하는 수집 원칙을 문서화한다.

## 기본 원칙
- **robots.txt 준수**: 크롤링 대상 도메인의 robots.txt를 확인하고, 허용된 경로만 요청한다.
- **서비스 약관 준수**: 각 사이트의 이용약관/정책에서 금지하는 자동화 수집은 수행하지 않는다.
- **최소 수집**: 업무 목적에 필요한 범위의 데이터만 수집한다.
- **개인정보 최소화**: 개인식별정보(PII)가 포함될 수 있는 데이터는 수집하지 않는다.
- **캐시/재사용**: 이미 수집한 데이터는 재요청하지 않도록 캐싱/중복 제거를 활용한다.

## 요청 빈도 정책
- 과도한 요청을 피하기 위해 **수집 주기**를 설정한다.
- 기본 주기: `SCRAPE_INTERVAL_HOURS` (예: 12시간)
- 필요 시 요청 간 **지연(딜레이)** 를 추가하여 서버 부하를 최소화한다.

## 실패/차단 대응
- HTTP 403/429/503 등 차단/과부하 신호가 감지되면 즉시 수집을 중단하고 주기를 늘린다.
- 반복 실패 시 수집을 비활성화하고 운영 검토 후 재개한다.

## 운영 체크리스트
- [ ] robots.txt 확인 완료
- [ ] 서비스 약관 확인 완료
- [ ] 요청 빈도 정책 적용 완료
- [ ] 개인정보 수집 여부 검토 완료
- [ ] 실패/차단 대응 로직 확인

## 참고
- 본 문서는 내부 운영 기준이며, 실제 운영 전 법무/보안 검토가 필요할 수 있다.
